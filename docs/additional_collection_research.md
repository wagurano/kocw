# KOCW 추가 수집 가능 정보 조사 보고서

> 작성일: 2026-09-27
> 대상: KOCW(한국OpenCourseWare) 서비스 종료(2026-12-30) 전 추가 수집 가능한 데이터 항목 조사
> 작성자: kocw-archive 프로젝트

## 1. 조사 배경 및 목적

KOCW는 2026년 12월 30일 서비스 종료를, 신규 회원가입은 2026년 9월 30일에 종료할 예정입니다. 본 보고서는 메인 수집 대상(강의 메타데이터, 공지사항, 뉴스레터, 통계) 외에 추가로 수집 가능한 데이터 항목을 조사하여 아카이브의 완전성을 높이기 위한 의사결정 자료를 마련합니다. 각 항목별로 **공개 여부, 접근 조건, 수집 방법, 법적/윤리적 고려사항, 예상 작업량**을 평가합니다.

## 2. 조사 대상 항목별 상세 분석

### 2.1 사용자 의견/댓글 (Search Comment)

**Endpoint:** `/home/search/searchComment.do`
**공개 범위:** 강의 단위로 공개(비로그인 조회 가능), 단 전체 이력은 로그인 필요
**접근 조건:** kemId 파라미터 + RISS 계정(전체 수집 시)
**수집 방법:** 강의 목록(lecture)을 1차 수집한 뒤, 각 강의의 kemId로 댓글 엔드포인트를 순회 호출
**데이터 형태:** 강의평, 평점, 작성자ID(마스킹), 작성일, 좋아요 수 등
**윤리적 고려사항:** 작성자 동의 없이 평문 보관은 개인정보 보호법 이슈 발생 가능. 작성자ID는 마스킹 처리하거나 비식별화 권장
**예상 작업량:** MEDIUM — 강의 수(약 5,000건 기준) × 댓글 페이지네이션, Rate Limit 적용 시 약 2~3일
**권장 등급:** 🟡 MEDIUM (집계 통계만 우선 수집)

### 2.2 수강확인증 (Certificate of Completion)

**위치:** 내강의실 > 수강확인증강의
**공개 범위:** 본인 발급 이력만(타인 조회 불가)
**접근 조건:** RISS 계정 + 실제 강의 등록 + 진도율 95% 이상 도달
**수집 방법:** 자동화 불가 — 사람 개입 필수. 강의별로 학습자가 직접 수료 후 발급
**데이터 형태:** PDF/이미지, 수료일, 강의 정보, 발급자
**윤리적 고려사항:** 타인의 수강확인증을 임의 수집하는 것은 법적/윤리적으로 부적절
**예상 작업량:** LOW 우선순위 — 자동화 불가, 자원 대비 가치 낮음
**권장 등급:** 🔴 LOW (수집 대상에서 제외)

### 2.3 내강의클립 / 강의담기 (Personal Course Lists)

**위치:** 내강의실 > 내강의클립, 강의담기
**공개 범위:** 개인 한정(다른 사용자에게 비공개)
**접근 조건:** 개별 사용자 계정 필요, 본인 데이터
**수집 방법:** 사용자별 로그인 후 API/페이지 파싱
**데이터 형태:** 강의 ID 목록, 폴더명, 담기 일시, 메모
**윤리적 고려사항:** 개인화된 데이터로 본인의 명시적 동의 없는 수집/공개는 개인정보보호법 위반
**예상 작업량:** LOW 우선순위 — 다수 계정 필요, 법적 리스크 높음
**권장 등급:** 🔴 LOW (수집 대상에서 제외)

### 2.4 OPEN API 호출 로그 (Search KemStat)

**Endpoint:** `/home/search/searchKemStat.do`
**공개 범위:** API 키 발급자에게 한해 메타데이터 열람 가능
**접근 조건:** RISS에 OPEN API 신청 및 승인, API 키 필요
**수집 방법:** 발급된 키로 REST 호출, JSON/XML 응답 파싱
**데이터 형태:** API 호출 횟수, 호출자 IP, 시간대별 트래픽, 강의별 통계
**윤리적 고려사항:** 키의 남용/공유는 계약 위반, 정상 범위 내 호출 필요
**대안 데이터:** `kocwstats.netlify.app`에서 캐시된 시계열 통계 확인 가능
**예상 작업량:** MEDIUM — API 신청 절차(2~3주 소요) + 응답 파싱 파이프라인 구축
**권장 등급:** 🟡 MEDIUM (netlify.app 데이터로 대체 가능)

### 2.5 수강신청 데이터 (Enrolment Data)

**위치:** 수강확인증 통계 페이지
**공개 범위:** 집계 통계만(개인 단위 데이터 없음)
**접근 조건:** 대시보드 직접 접근, 로그인 불필요 가능성
**수집 방법:** 월별/분기별 집계 페이지 HTML 파싱
**데이터 형태:** 강의별 수강신청 수, 수료율, 기간별 추이
**윤리적 고려사항:** 집계 통계는 비식별화되어 있으므로 법적 이슈 없음
**예상 작업량:** SMALL — 페이지 수 적음, 단순 스크래핑 가능
**권장 등급:** 🟢 HIGH (가성비 우수)

### 2.6 강의추천 (Course Recommendations)

**Endpoint:** `/home/search/searchRecommend.do`
**공개 범위:** 강의별 추천 수 공개(비로그인 조회 가능)
**접근 조건:** 없음(공개 API)
**수집 방법:** 강의 ID로 추천 카운트 정수 조회
**데이터 형태:** 강의별 추천 수(단일 정수)
**윤리적 고려사항:** 공개된 카운트 데이터이므로 제약 없음
**예상 작업량:** SMALL — 강의 수만큼 단순 반복, 초당 수십 건 처리 가능
**권장 등급:** 🟢 HIGH (강의 메타데이터 수집 시 함께 처리 가능)

## 4. 권장 우선순위

1. **1순위 (즉시 수집)**: 강의추천, 수강신청 통계 — 강의 메타데이터 수집 사이클에 병합하여 처리
2. **2순위 (여유 시 수집)**: 사용자 의견/댓글 — 작성자ID 비식별화 후 강의 ID별 집계치만 보존
3. **3순위 (netlify.app로 대체)**: OPEN API 호출 로그 — 별도 신청 절차 없이 기존 캐시 활용
4. **수집 제외**: 수강확인증, 내강의클립 — 자동화 불가 + 개인정보 리스크

## 5. 타임라인 고려사항

- **2026-09-30**: 신규 회원가입 종료 → 2.2(수강확인증), 2.3(내강의클립) 자동화 가능성 영구 차단
- **2026-12-30**: 서비스 전체 종료 → 모든 엔드포인트(`/home/search/*`) 응답 불가
- **여유 기간**: 약 3개월(≈90일). 우선순위 HIGH 항목을 메인 파이프라인과 함께 1주일 내 처리하고, MEDIUM 항목은 2주 버퍼를 두고 점진 수집
- **리스크**: KOCW 측의 사전 점검/접속 제한 가능성에 대비해 수집 스크립트는 idempotent + resume-safe 설계 필수

## 6. 결론 및 권고사항

본 조사 결과, 메인 아카이브 파이프라인에 **강의추천(6번)**과 **수강신청 통계(5번)**를 통합하는 것이 가장 효율적입니다. 두 항목 모두 공개 데이터이며 강의 메타데이터 수집 시 자연스럽게 누적할 수 있어 추가 인프라 비용이 발생하지 않습니다. 사용자 의견/댓글(1번)은 가치 대비 법적 검토 비용이 높아 **마스킹된 집계치만 선택적 수집**을 권장합니다. 수강확인증(2번)과 내강의클립(3번)은 자동화가 사실상 불가능하고 개인정보 리스크가 커서 본 아카이브 범위에서 제외합니다. OPEN API 로그(4번)는 별도 키 신청 절차가 필요하므로, 이미 운영 중인 `kocwstats.netlify.app` 시계열 데이터를 우선 활용하는 것이 현명합니다.
